Shifter extension build instructions

Production packages use the live Shifter API and real browser proxy controller. Source includes the toolbar connection badge and country-wide state, city and ASN search.

Version 0.1.1: preserve dashboard sessions

Removed cookie deletion from connect, switch and disconnect, and removed the browsingData permission from Chrome and Edge. Switching credentials now selects a gateway hostname/port with matching or unused cached credentials. It never clears website cookies.

Gateway aliases are finite. Chrome and Edge stop the connection and ask for a browser restart when no compatible address remains, instead of silently using an old country or session. Pinning an entry point reduces the available addresses. ISP plans exposing only one address require a browser restart when changing the proxy username. Firefox retains its existing restart warning.

Verification: Chrome and Firefox end-to-end suites passed, including eight consecutive session changes. Chrome and Edge builds passed a local HTTPS regression in Chrome for Testing: all five test cookies on shifter.io (including HttpOnly session and remember-me cookies) survived connect, two country switches, a new session, rotating mode, disconnect and exhausted-address handling. The fixture dashboard continued receiving the cookies after reload. Gateway logs confirmed new usernames on switches, and an already open site stopped using the proxy after disconnect. Edge itself and a real signed-in Shifter dashboard were not tested in this environment.

Environment

Build locally with Node.js 24.21.0 and npm 11.19.0. Extract the source archive into a clean directory. The included package-lock.json pins dependencies. Network access is needed to download npm dependencies; no API credentials are needed to build.

Use a clean shell without WXT_* environment overrides and without local .env files. In particular, do not enable WXT_USE_MOCK, WXT_SHIFTER_BASE_URL, WXT_GATEWAY_PORTS or WXT_OUT_DIR for store builds.

Reproduce Firefox

npm ci
npm run compile
npm run zip:firefox

The upload package is build/shifter-proxy-extension-0.1.1-firefox.zip. Its unpacked contents are in build/firefox-mv2/. The separately generated build/shifter-proxy-extension-0.1.1-sources.zip is the reviewer source archive.

Chrome and Edge

npm run zip
npx wxt zip -b edge

These produce build/shifter-proxy-extension-0.1.1-chrome.zip and build/shifter-proxy-extension-0.1.1-edge.zip. Upload the browser-specific ZIP with manifest.json at its root.

Included assets

The location catalog, icons, flags and fonts are included. Do not regenerate them to reproduce this release: the build uses src/lib/geo/catalog.json and the files under public/ directly. Source for the catalog and icon generators is included for reference; running those generators is not a build step.

Review notes

Firefox uses Manifest V2 and Chrome/Edge use Manifest V3. The Firefox extension ID is extension@shifter.io. A valid Shifter API key and active proxy membership are required to test an actual connection; no account credentials are bundled.

The ZIPs are unsigned upload packages. Store submission, listing information and store signing are separate from this local build.

Reference: Mozilla source submission instructions and Chrome Web Store publishing.
